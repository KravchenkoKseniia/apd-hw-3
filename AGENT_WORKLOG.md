- Known limitation or remaining risk:
  - UI tests use XCUITest's built-in idle synchronization instead of `waitForExistence` or sleeps (to follow the "no polling" rule), so a very slow CI machine could make them flaky.
  - Local tests run on Xcode 27.2, while CI runs on Xcode 26.2 after the workflow change, so the two environments are not identical.
  - The workflow now pins `Xcode_26.2.app`. If a future runner image removes that Xcode version, CI will need another update.
  - After the scene-delegate fix, an already installed older build may show a black screen until the app is deleted and reinstalled, because iOS restores the saved scene session. Fresh installs (tests, CI) are not affected.
  - Tests now run serially (shared scheme with `parallelizable = "NO"`), which is slower but avoids the clone being killed on the GitHub runner. If CI still kills the simulator, the cause is runner resources rather than app code.
  - Optional add/edit/delete bonus is not implemented.
